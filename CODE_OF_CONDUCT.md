# Code of conduct

Be respectful. Do not harass anyone. Do not publish others' private information.

This is an alpha technical project. Keep discussion about the software.

Unacceptable behaviour may result in a warning or a ban from the issue tracker
and pull requests, at the maintainers' discretion.

Report conduct problems the same way as security issues when they involve
private information: use GitHub private reporting rather than a public issue.
See [SECURITY.md](SECURITY.md).
